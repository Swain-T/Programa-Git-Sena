# Proyecto TaskFlow

Sistema sencillo desarrollado en Java para gestionar usuarios.

## Funcionalidades
- Registrar nuevos usuarios.
- Consultar la lista de usuarios.
- Actualizar datos de usuario.
- Eliminar usuarios del sistema.

## Tecnología utilizada
- Lenguaje: Java
- Base de datos: MySQL
